# 购票会员小程序

独立微信原生小程序，包含首页、公共浴池门票、私汤连续场次预约、订单、会员中心与储值。

- 票价、私汤价格、可售量和余额全部来自服务端。
- 预约不选择房号，到店后由前台分房。
- 园内点餐已移至独立 `frontend_2`，本项目不包含点餐页面。
- 本机 `project.config.json` 可能已由微信开发者工具写入真实 AppID；提交前确认它是购票会员端自己的 AppID，且不得与点餐端相同。仓库不保存 AppSecret。
- `config.js` 的 `apiBase` 指向本地 FastAPI；`development: true` 明确启用开发令牌和 Mock 支付。

```powershell
npm test
```

正式发布前必须实现正式微信登录、支付适配器和支付结果服务端查询，并关闭开发 Mock。WXML 真机表现需要微信开发者工具验证。
