# 独立私汤房点餐小程序

从每间私汤房二维码进入的独立微信原生小程序。AppID 占位 `wx0000000000000002`，不得与购票会员端共用。

- 房间码 scene：`ROOM-01` 至 `ROOM-17`，或链接 `?scene=ROOM-01`；进入后也可在顶部选择送餐房间。
- 点餐页左侧为营业商家，右侧为该商家商品；切换商家会清空当前购物车。
- 真机预览必须把 `config.js` 的 `apiBase` 改为运行后端的电脑局域网 IP，并确保手机与电脑同一 Wi-Fi；`127.0.0.1` 只适用于电脑模拟器。
- 加载失败会在页面保留错误原因和“重新加载”按钮，不再只显示短暂的 Toast。
- 任何扫码者可浏览菜单并使用本人微信支付。
- 会员余额只有在用户明确登录并完成会员归属验证后才可选；房间码本身不授予余额权限。
- 订单展示送达房号、商家接单/制作/已送达状态；无法送达时只显示前台人工处理。
- 开发环境使用 Mock 支付并清楚标注，不产生真实微信扣款。

```powershell
npm test
```

真实微信登录、AppID/OpenID 绑定、UnionID 可用性、商户号和支付能力仍需甲方与微信平台确认并在开发者工具/真机联调。
