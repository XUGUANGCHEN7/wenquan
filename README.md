# 蜀南温泉微信原生小程序

这是根据 UI 概念稿转换的微信原生小程序前端，可直接使用微信开发者工具导入。

## 导入方式

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件夹 `wechat-mini-program`。
3. 将 `project.config.json` 中的 `appid` 替换为正式小程序 AppID。
4. 当前图片使用 Unsplash 作为设计占位。开发阶段可关闭合法域名校验；发布前应下载图片到项目或替换为已配置的 CDN。

## 当前页面

- 首页：公共浴池购票、私汤房预约、点餐、储值入口
- 公共浴池购票：日期、时段、人数与金额联动
- 私汤房预约：房内环境、房型、日期与时段
- 商家列表：园内所有商家及营业信息
- 商家菜单：分类、商品加购、购物车金额联动
- 我的：余额、订单入口和常用服务
- 储值中心：余额、充值档位、充值活动

## 接口说明

当前数据为页面内 Mock 数据，支付按钮只做交互提示。正式上线前需要接入登录、商品、库存、订单、微信支付、退款、核销和储值等服务端接口。
