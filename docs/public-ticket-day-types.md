# 公共浴池不指定日期购票

已确认的规则：工作日票适用于非节假日的周一至周五；节假日票适用于周六、周日及后台 `is_holiday=true` 的日期。两类各有成人与儿童价格；付款后精确30天有效，到期时刻不再允许核销。一个订单选择一种日期类型，最多20张。

小程序不传入园日期，提交 `day_type=WEEKDAY/HOLIDAY`；票价读取 `/catalog/ticket-products`，下单时由服务端重新定价并保存快照。儿童票价分别配置，初始沿用已有儿童价格。后台按日期配置的特殊价格继续作用于旧版日期订单，新票种只读取对应的四项产品价格。

新订单保存空的 `visit_date`、日期类型、有效期天数及付款后生成的截止时刻。原日期订单保留原数据及核验行为。订单详情、列表及前台均展示票种和有效期。过期或日期类型不符时，单票与整批核销均由服务端拒绝；重复请求仍沿用原幂等处理。

数据库变更：`f4a5b6c7d8e9`。部署先执行 `python -m alembic upgrade head`，再启动后端与更新小程序、Web。迁移不更改原有票价和订单金额。已有不指定日期订单时不允许直接降级至日期必填的旧结构。
